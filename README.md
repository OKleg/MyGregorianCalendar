# Григорианский календарь (Java)

Простая консольная программа на Java, которая принимает на вход номер года и возвращает полную календарную сетку на все 12 месяцев. 


##  Как запустить (Для пользователей)

Самый простой способ запустить программу — скачать готовый архив из раздела **Releases** на GitHub. Внутри архива уже находятся все необходимые файлы.

1. Убедитесь, что у вас установлена **Java 17 или выше** (`java -version`).
2. Распакуйте скачанный ZIP-архив.
3. Запустите программу в один клик под вашу операционную систему:
   * **Windows:** Дважды кликните по файлу `run.bat`
   * **macOS / Linux:** Запустите скрипт `run.sh`

Программа предложит ввести год и выбрать удобный формат вывода (красивый текстовый или структурированный JSON).

---

### Как собрать проект вручную:
Чтобы собрать готовый к переносу и запуску один файл со всеми зависимостями (Fat JAR), выполните команду в корне проекта:
```bash
mvn clean package
```
Результат сборки появится в папке `target/`. Запустить его на любом компьютере с Java можно командой:
```bash
java -jar target/*-jar-with-dependencies.jar
```
